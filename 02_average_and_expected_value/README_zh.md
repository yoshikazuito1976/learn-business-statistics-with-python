## 什么是平均值

平均值是把多个数值“平滑”后得到的代表值。

```text
2, 4, 6, 8, 10
(2 + 4 + 6 + 8 + 10) / 5 = 6
```

平均值很有用，但只看平均值往往不够。

## 什么是期望值

期望值是随机事件重复很多次后的平均结果。

若中奖概率 10%，抽 10 次：

```text
10 x 0.1 = 1
```

期望中奖次数是 1。
但这不代表每次都一定中 1 次。

## 期望值的具体例子

1. 广告点击: 100 x 0.05 = 5
2. 销售成交: 30 x 0.1 = 3
3. 咨询处理时间: 20 x 12 = 240 分钟
4. 销售额预估: 100 x 3000 = 300000
5. 抽奖/扭蛋: 100 x 0.02 = 2
6. 缺席人数预估: 40 x 0.05 = 2
7. 不良品预估: 1000 x 0.01 = 10

这些都是“平均层面的预估”，不是单次保证。

## Python 模拟示例

```python
import random

p = 0.1
trials_per_set = 10
set_count = 1000
results = []

for _ in range(set_count):
    win_count = 0
    for i in range(trials_per_set):
        if random.random() < p:
            win_count += 1
    results.append(win_count)

print(sum(results) / len(results))
```

## 业务联系

平均值与期望值可用于：
- 点击预测
- 成交预测
- 工时估算
- 销售预测

但不能只看平均值，还要结合波动与风险。

## 小结

- 平均值是代表值
- 期望值是重复随机事件的平均预估
- 期望值不是单次结果保证
- 平均值相同不代表数据状态相同
