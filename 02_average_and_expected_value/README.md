# 02 Average and Expected Value

## 日本語

この章では、平均と期待値について学びます。

前の章では、10%で当たるくじを題材にして、1回の結果と繰り返したときの傾向の違いを確認しました。

この章では、その考えを一歩進めて、次の問いを考えます。

> 10%で当たるくじを10回引いたら、平均すると何回くらい当たりそうか

ここで考えるのは、「10回引いて1回以上当たる確率」ではありません。  
繰り返したときの結果を平均すると、どのくらいになりそうかということです。

## この章の目的

この章では、次のことを理解することを目指します。

- 平均とは何か
- 期待値とは何か
- 期待値は「必ずそうなる結果」ではないこと
- 確率と回数をかけると、平均的な結果を考えられること
- Python を使って、平均や期待値をシミュレーションで確認できること
- ビジネス判断において、平均をどう扱うかを考えられること

## 平均とは何か

平均とは、複数の数値をならして、全体としてどのくらいかを表す値です。

例えば、次のようなデータがあるとします。

```text
2, 4, 6, 8, 10
```

この平均は、すべての値を足して、データの個数で割ることで求められます。

```text
(2 + 4 + 6 + 8 + 10) / 5 = 6
```

平均は、データ全体を1つの値で代表させるための便利な指標です。

ただし、平均だけで全体を完全に説明できるわけではありません。

## Pythonで平均を計算する

Python では、リストに入れた数値を使って平均を計算できます。

```python
values = [2, 4, 6, 8, 10]

average = sum(values) / len(values)

print(average)
```

`sum(values)` は、リストの中の数値をすべて足します。  
`len(values)` は、リストの中にいくつの値があるかを数えます。

平均は、「合計を個数で割る」という考え方です。

## 期待値とは何か

期待値とは、確率的な出来事を何度も繰り返したときに、平均するとどのくらいになりそうかを表す考え方です。

例えば、10%で当たるくじを10回引くとします。

1回あたり当たる確率は 0.1 です。  
10回引くので、平均すると次のように考えられます。

```text
10 × 0.1 = 1
```

つまり、10回引いたときの当たり回数の期待値は 1回です。

ここで大切なのは、期待値は「必ずそうなる結果」ではないということです。

10回引いた結果は、0回当たりかもしれません。  
1回当たりかもしれません。  
2回以上当たるかもしれません。

期待値は、同じ条件で何度も繰り返したときに、平均するとそのくらいになりそうだ、という考え方です。

## 期待値と実際の結果は違う

10%で当たるくじを10回引いたとき、期待値は1回です。

しかし、1回の実験結果が必ず1回になるわけではありません。

例えば、10回引く実験を何セットも繰り返すと、次のような結果になることがあります。

```text
0回, 1回, 2回, 1回, 0回, 3回, 1回, 2回, ...
```

1セットごとの結果にはばらつきがあります。

しかし、たくさんのセットを集めて平均すると、1回に近づいていく傾向があります。

## 期待値の具体例

期待値は、さまざまな場面で「全体の見込み」を考えるために使えます。

### 例1: 広告のクリック数

広告のクリック率が 5% だとします。

100人に広告を表示した場合、期待されるクリック数は次のとおりです。

```text
100 × 0.05 = 5
```

つまり、平均すると 5クリックくらい が期待できます。

ただし、実際には3クリックかもしれないし、8クリックかもしれません。  
期待値は「必ず5クリックされる」という意味ではありません。

### 例2: 営業の成約数

営業の成約率が 10% だとします。

30件営業した場合、期待される成約数は次のとおりです。

```text
30 × 0.1 = 3
```

つまり、平均すると 3件くらい成約しそう と考えられます。

しかし、実際には0件のこともあります。  
逆に、5件以上成約することもあります。

ここで大切なのは、成約率10%だから、10件営業すれば必ず1件決まるわけではない、ということです。

### 例3: 問い合わせ対応時間

1件あたりの問い合わせ対応時間が平均12分だとします。

20件対応する場合、期待される対応時間は次のとおりです。

```text
20 × 12 = 240
```

つまり、合計で 240分、つまり4時間くらい かかると見積もれます。

ただし、すべての問い合わせが12分で終わるわけではありません。

簡単な問い合わせは3分で終わるかもしれません。  
難しい問い合わせは30分かかるかもしれません。

それでも平均を使うことで、全体の作業量を見積もることができます。

### 例4: 平均購入金額と売上見込み

1人あたりの平均購入金額が 3000円 だとします。

100人が購入した場合、期待される売上は次のとおりです。

```text
100 × 3000 = 300000
```

つまり、30万円くらいの売上 が期待できます。

ただし、実際には全員が3000円ちょうど買うわけではありません。

ある人は1000円だけ買うかもしれません。  
別の人は10000円買うかもしれません。

平均購入金額は、個人の購入額を保証するものではなく、全体の見込みを考えるための値です。

### 例5: ガチャ・くじ・抽選

当たりの確率が 2% のガチャがあるとします。

100回引いた場合、期待される当たり回数は次のとおりです。

```text
100 × 0.02 = 2
```

つまり、平均すると 2回くらい当たりそう と考えられます。

しかし、これは「100回引けば必ず2回当たる」という意味ではありません。

0回のこともあります。  
1回のこともあります。  
3回以上当たることもあります。

この例は、確率と期待値の違いを直感的に理解しやすい題材です。

### 例6: 欠席・遅刻の見込み

あるクラスで、1人がある日に欠席する確率が 5% だとします。

学生が40人いる場合、その日に欠席する人数の期待値は次のとおりです。

```text
40 × 0.05 = 2
```

つまり、平均すると 2人くらい欠席しそう と考えられます。

ただし、実際には0人かもしれません。  
5人欠席する日もあるかもしれません。

期待値は、個別の1日を正確に予言するものではなく、全体の見込みを考えるためのものです。

### 例7: 不良品の数

ある製品の不良率が 1% だとします。

1000個作った場合、不良品の期待数は次のとおりです。

```text
1000 × 0.01 = 10
```

つまり、平均すると 10個くらい不良品が出そう と考えられます。

ただし、実際には8個かもしれないし、15個かもしれません。

製造や品質管理では、このように期待値を使って、検査体制や対応コストを考えることがあります。

## Pythonで期待値を確認する

10%で当たるくじを10回引く実験を、1000セット繰り返してみます。

```python
import random

p = 0.1
trials_per_set = 10
set_count = 1000

results = []

for set_number in range(set_count):
    win_count = 0

    for i in range(trials_per_set):
        if random.random() < p:
            win_count += 1

    results.append(win_count)

average_wins = sum(results) / len(results)

print("平均当たり回数:", average_wins)
```

実行すると、平均当たり回数は 1 に近い値になるはずです。

ただし、毎回ぴったり1になるとは限りません。

## 平均は便利だが、注意も必要

平均は、全体の傾向をつかむために便利です。

しかし、平均だけを見ると、データのばらつきや極端な値を見落とすことがあります。

例えば、次の2つのデータを比べてみます。

```text
A: 4, 5, 6
B: 0, 5, 10
```

どちらも平均は 5 です。

しかし、Aは値が5の近くに集まっています。  
Bは値が大きくばらついています。

このように、平均が同じでも、データの状態が同じとは限りません。

平均を見るときは、次の章で学ぶ分散や標準偏差とあわせて考えることが重要です。

## ビジネスとのつながり

ビジネスでは、平均や期待値を使って、将来の見込みを考えることがあります。

例えば、次のような場面です。

- 広告のクリック率が10%のとき、100回表示したら何クリックくらい期待できるか
- 成約率が5%のとき、200件営業したら何件くらい成約しそうか
- 平均購入金額が3000円のとき、100人が購入したら売上はいくらくらいになりそうか
- 1件あたりの問い合わせ対応時間が平均10分のとき、50件でどれくらい時間が必要か

ただし、期待値や平均は「見込み」です。

実際の結果は、期待値より多いことも少ないこともあります。

そのため、ビジネスでは平均だけでなく、ばらつきやリスクも一緒に考える必要があります。

## この章で大切な考え方

平均は、複数のデータをならして、全体の代表値として見る考え方です。

期待値は、確率的な出来事を繰り返したときに、平均するとどのくらいになりそうかを見る考え方です。

どちらも、全体の傾向をつかむために役立ちます。

しかし、平均や期待値は、1回の結果を保証するものではありません。
