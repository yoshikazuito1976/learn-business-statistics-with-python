# 04 Histogram and Distribution

## この章の目的

この章では、データの「分布」を確認する方法を学びます。

平均値や標準偏差は、データ全体の特徴を数値でまとめる便利な指標です。
しかし、平均値だけを見ても、データがどのように散らばっているのかはわかりません。

たとえば、同じ平均点でも、

- ほとんどの人が平均点付近に集まっている
- 高得点と低得点に大きく分かれている
- 一部の極端な値が平均を引き上げている

というように、データの姿は大きく異なります。

そこで、この章では次の流れでデータを観察します。

```text
個々のデータ
↓
度数分布表
↓
ヒストグラム
↓
分布の読み取り
```

## 度数分布表とは

度数分布表とは、データをいくつかの範囲に分け、それぞれの範囲に何個のデータが入っているかを表にしたものです。

たとえば、テストの点数データがあるとします。

```python
scores = [45, 52, 58, 61, 63, 67, 70, 72, 75, 78, 80, 82, 85, 88, 92]
```

このデータをそのまま眺めても、全体の傾向は少しわかりにくいです。

そこで、点数を範囲ごとに分けます。

| 点数の範囲 | 人数 |
| --- | ---: |
| 40点以上50点未満  |  1 |
| 50点以上60点未満  |  2 |
| 60点以上70点未満  |  3 |
| 70点以上80点未満  |  4 |
| 80点以上90点未満  |  4 |
| 90点以上100点以下 |  1 |

このように、データを範囲ごとに整理した表が度数分布表です。

## 度数とは

度数とは、その範囲に含まれるデータの個数のことです。

たとえば、70点以上80点未満の範囲に4人いる場合、この範囲の度数は4です。

```text
度数 = その範囲に入っているデータの数
```

度数分布表を見ることで、どのあたりにデータが多いのか、どのあたりにデータが少ないのかを確認できます。

## 階級とは

度数分布表では、データをいくつかの範囲に分けます。
この範囲のことを階級と呼びます。

たとえば、次のような範囲が階級です。

```text
40点以上50点未満
50点以上60点未満
60点以上70点未満
```

階級を作ることで、細かいデータを大きなまとまりとして見ることができます。

## 階級幅とは

階級幅とは、階級の幅のことです。

たとえば、次の階級では、階級幅は10点です。

```text
40点以上50点未満
```

50 - 40 = 10 なので、階級幅は10になります。

階級幅を広くすると、全体の傾向は見やすくなりますが、細かい違いは見えにくくなります。
階級幅を狭くすると、細かい違いは見えやすくなりますが、全体の傾向がつかみにくくなることがあります。

## Pythonで度数分布表を作る

Pythonでは、`pandas` を使って度数分布表を作ることができます。

```python
import pandas as pd

scores = [45, 52, 58, 61, 63, 67, 70, 72, 75, 78, 80, 82, 85, 88, 92]

bins = [40, 50, 60, 70, 80, 90, 100]
labels = [
    "40点以上50点未満",
    "50点以上60点未満",
    "60点以上70点未満",
    "70点以上80点未満",
    "80点以上90点未満",
    "90点以上100点以下"
]

score_groups = pd.cut(scores, bins=bins, labels=labels, right=False)
frequency_table = score_groups.value_counts().sort_index()

print(frequency_table)
```

実行すると、点数の範囲ごとの人数を確認できます。

## ヒストグラムとは

ヒストグラムとは、度数分布表をグラフにしたものです。

度数分布表は表なので、数値を正確に確認しやすいです。
一方で、ヒストグラムはグラフなので、データの分布の形を直感的に理解しやすいです。

```text
度数分布表：範囲ごとの個数を表で見る
ヒストグラム：範囲ごとの個数をグラフで見る
```

つまり、ヒストグラムのもとになるデータが度数分布表です。

## Pythonでヒストグラムを描く

Pythonでは、`matplotlib` を使ってヒストグラムを描くことができます。

```python
import matplotlib.pyplot as plt

scores = [45, 52, 58, 61, 63, 67, 70, 72, 75, 78, 80, 82, 85, 88, 92]

plt.hist(scores, bins=[40, 50, 60, 70, 80, 90, 100], edgecolor="black")

plt.title("Histogram of Test Scores")
plt.xlabel("Score")
plt.ylabel("Frequency")

plt.show()
```

このヒストグラムを見ると、どの点数帯に学生が多いのかがわかります。

## ヒストグラムから読み取ること

ヒストグラムを見ると、次のようなことを確認できます。

### 1. データがどこに集まっているか

山が高いところは、データが多く集まっている範囲です。

たとえば、70点台や80点台の棒が高ければ、多くの学生がその点数帯に集まっていることがわかります。

### 2. データがどのくらい散らばっているか

ヒストグラムが横に広がっていれば、データのばらつきが大きいと考えられます。
逆に、狭い範囲に集中していれば、ばらつきは小さいと考えられます。

### 3. 極端な値があるか

他のデータから大きく離れた場所に少数のデータがある場合、外れ値の可能性があります。

たとえば、多くの学生が60点から80点にいるのに、1人だけ10点台の学生がいる場合、その値は特別に確認する必要があるかもしれません。

### 4. 山が1つか、複数あるか

ヒストグラムの山が1つであれば、データは1つのまとまりとして見やすいです。

一方で、山が2つある場合は、データの中に異なるグループが混ざっている可能性があります。

たとえば、あるクラスのテスト結果で山が2つある場合、

- すでに理解している学生のグループ
- まだ理解が不十分な学生のグループ

に分かれている可能性があります。

## ビジネスでの活用例

ヒストグラムや度数分布表は、ビジネスでもよく使われます。

### 売上金額の分布

顧客ごとの購入金額をヒストグラムにすると、次のようなことがわかります。

- 少額購入の顧客が多いのか
- 高額購入の顧客が一部だけ存在するのか
- 平均購入額が一部の大口顧客に引き上げられていないか

### 問い合わせ対応時間の分布

問い合わせ対応にかかった時間をヒストグラムにすると、次のようなことがわかります。

- 多くの問い合わせは短時間で対応できているのか
- 一部の問い合わせだけ極端に時間がかかっているのか
- 対応時間にばらつきがあるのか

### テスト点数の分布

学生のテスト点数をヒストグラムにすると、次のようなことがわかります。

- 全体的に理解できているのか
- 得点が二極化していないか
- 補習が必要な層がどのくらいいるのか

## 平均値だけでは見えないこと

平均値は便利な指標ですが、平均値だけでは分布の形はわかりません。

たとえば、次の2つのクラスは、どちらも平均点が同じくらいになるかもしれません。

```text
クラスA：多くの学生が平均点付近に集まっている
クラスB：高得点者と低得点者に分かれている
```

この場合、平均点だけを見ると、2つのクラスは似ているように見えます。
しかし、ヒストグラムを見ると、学習状況が大きく違うことがわかります。

つまり、データを見るときは、平均値だけでなく、分布も確認することが大切です。
