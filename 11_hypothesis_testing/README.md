# 11 Hypothesis Testing

## この章の目的

この章では、仮説検定を「正解を出す魔法」ではなく、
不確実な状況で判断するための形式として学びます。

## 基本用語

- 帰無仮説 (H0): 差がない、効果がない、関係がないという基準仮説
- 対立仮説 (H1): 差がある、効果がある、関係があるという仮説
- 有意水準 (alpha): H0 を誤って棄却してしまうリスクの許容値（例: 0.05）
- p値: H0 が正しいと仮定したとき、観測結果以上の極端さが出る確率
- t値: 標本差を標準誤差で割った統計量（平均との差がどれだけ離れているかの指標）
- 棄却: p値 < alpha なので H0 と整合しにくいと判断する
- 棄却できない: H0 を覆す証拠が十分でない

## 大事な考え方

「棄却できない」は「差がないことを証明した」ではありません。

正しくは、
「このデータだけでは、差があると言い切る証拠が足りなかった」
という意味です。

## ビジネス例

A/B広告でクリック率に差があるかを検討する前に、
まず検定の枠組みを文章で定義します。

- H0: AとBの平均クリック率に差はない
- H1: AとBの平均クリック率に差がある
- alpha: 0.05

## 最小コード例（t統計量とp値）

```python
import numpy as np
from scipy import stats

np.random.seed(7)
a = np.random.normal(loc=0.10, scale=0.03, size=40)
b = np.random.normal(loc=0.12, scale=0.03, size=40)

t_stat, p_value = stats.ttest_ind(a, b, equal_var=False)
print("t:", t_stat)
print("p:", p_value)
```

## 判断の流れ

1. 仮説を決める
2. 有意水準を先に決める
3. 検定統計量と p値を計算する
4. 棄却/棄却できないを判断する
5. 効果量や業務インパクトと合わせて意思決定する
