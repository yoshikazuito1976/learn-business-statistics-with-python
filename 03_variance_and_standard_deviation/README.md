# 03 分散と標準偏差

## この章の目的

この章では、平均値だけではわからない「データのばらつき」を扱います。

平均値は、データ全体の中心を表す便利な値です。
しかし、平均値が同じでも、データの散らばり方が同じとは限りません。

たとえば、次の2つのデータを比べてみます。

```text
A: 48, 49, 50, 51, 52
B: 10, 30, 50, 70, 90
```

どちらも平均値は 50 です。

しかし、A は 50 の近くに集まっています。
一方、B は 50 から大きく離れた値を含んでいます。

つまり、平均値だけでは「データがどれくらい散らばっているか」はわかりません。

そこで使うのが、分散と標準偏差です。

---

## 平均値だけでは見えないもの

平均値は、データの中心を表します。

しかし、ビジネスの現場では、中心だけでなく「安定しているか」「ばらつきが大きいか」も重要です。

たとえば、次のような場面があります。

- 売上が毎日安定しているか
- 来店者数の変動が大きいか
- テストの点数がクラス全体でばらついているか
- 作業時間に個人差があるか
- 商品レビューの評価が安定しているか

平均値が同じでも、ばらつきが大きいデータと小さいデータでは、判断が変わることがあります。

---

## ばらつきを考える第一歩

ばらつきを考えるには、まず各データが平均値からどれくらい離れているかを見ます。

この「平均との差」を偏差と呼びます。

```text
偏差 = データの値 - 平均値
```

たとえば、次のデータを考えます。

```text
40, 50, 60
```

平均値は 50 です。

それぞれの平均との差は次のようになります。

```text
40 - 50 = -10
50 - 50 = 0
60 - 50 = 10
```

平均との差を見ると、データが平均からどれくらい離れているかがわかります。

---

## 偏差をそのまま足すとどうなるか

偏差を足してみます。

```text
-10 + 0 + 10 = 0
```

合計は 0 になります。

これは偶然ではありません。
平均値からの差は、プラスとマイナスが打ち消し合うため、合計すると基本的に 0 になります。

そのため、偏差をそのまま平均しても、ばらつきの大きさは表せません。

---

## 二乗してから平均する

そこで、偏差を二乗します。

```text
(-10)^2 = 100
0^2 = 0
10^2 = 100
```

二乗すると、マイナスの値もプラスになります。

この二乗した偏差を平均したものが、分散です。

```text
分散 = 偏差の二乗の平均
```

今回の例では、

```text
(100 + 0 + 100) / 3 = 66.67
```

分散は 66.67 です。

---

## 分散とは何か

分散は、データが平均値からどれくらい離れているかを表す値です。

分散が小さいほど、データは平均値の近くに集まっています。
分散が大きいほど、データは平均値から大きく散らばっています。

ただし、分散には少しわかりにくい点があります。

それは、単位が二乗されてしまうことです。

たとえば、点数のデータであれば、分散の単位は「点の二乗」のようなものになります。
これは直感的には少し扱いにくいです。

---

## 標準偏差とは何か

そこで、分散の平方根を取ります。

分散の平方根を取ったものが、標準偏差です。

```text
標準偏差 = 分散の平方根
```

標準偏差は、元のデータと同じ単位でばらつきを表せます。

たとえば、点数のデータであれば、標準偏差も「点」として考えられます。

そのため、分散よりも標準偏差の方が、実際の感覚に近い指標として使いやすいです。

---

## Pythonで確認する

Pythonを使って、平均値、分散、標準偏差を計算してみます。

```python
data = [40, 50, 60]

mean = sum(data) / len(data)

deviations = []
for x in data:
    deviations.append(x - mean)

squared_deviations = []
for d in deviations:
    squared_deviations.append(d ** 2)

variance = sum(squared_deviations) / len(data)
standard_deviation = variance ** 0.5

print("平均:", mean)
print("偏差:", deviations)
print("偏差の二乗:", squared_deviations)
print("分散:", variance)
print("標準偏差:", standard_deviation)
```

---

## 2つのデータを比較する

平均値が同じでも、ばらつきが違う例を確認します。

```python
data_a = [48, 49, 50, 51, 52]
data_b = [10, 30, 50, 70, 90]

def calc_mean(data):
    return sum(data) / len(data)

def calc_variance(data):
    mean = calc_mean(data)
    squared_deviations = []
    for x in data:
        squared_deviations.append((x - mean) ** 2)
    return sum(squared_deviations) / len(data)

def calc_standard_deviation(data):
    variance = calc_variance(data)
    return variance ** 0.5

print("Aの平均:", calc_mean(data_a))
print("Aの分散:", calc_variance(data_a))
print("Aの標準偏差:", calc_standard_deviation(data_a))

print("Bの平均:", calc_mean(data_b))
print("Bの分散:", calc_variance(data_b))
print("Bの標準偏差:", calc_standard_deviation(data_b))
```

A と B は平均値が同じです。
しかし、分散と標準偏差は大きく異なります。

このことから、平均値だけで判断すると、データの特徴を見落とす可能性があることがわかります。

---

## NumPyを使った計算

Pythonでは、NumPyを使うと分散や標準偏差を簡単に計算できます。

```python
import numpy as np

data = [40, 50, 60]

print("平均:", np.mean(data))
print("分散:", np.var(data))
print("標準偏差:", np.std(data))
```

ただし、最初から便利な関数だけを使うと、何を計算しているのかわかりにくくなります。

まずは、

1. 平均を出す
2. 平均との差を出す
3. 差を二乗する
4. 二乗した値の平均を出す
5. 平方根を取る

という流れを理解することが大切です。

---

## ビジネスでの意味

分散や標準偏差は、ビジネスの判断にも使えます。

たとえば、次の2つの店舗があるとします。

```text
店舗Aの売上: 98, 100, 102, 99, 101
店舗Bの売上: 60, 140, 80, 120, 100
```

どちらも平均売上は 100 です。

しかし、店舗Aは安定しています。
店舗Bは日によって売上の変動が大きいです。

この場合、平均売上だけを見ていると、店舗Bの不安定さに気づけません。

標準偏差を見ることで、売上の安定性やリスクを考えることができます。

---

## この章のまとめ

- 平均値はデータの中心を表す
- 平均値だけでは、データのばらつきはわからない
- 各データと平均値の差を偏差という
- 偏差をそのまま足すと、プラスとマイナスが打ち消し合う
- 偏差を二乗して平均したものが分散
- 分散の平方根を取ったものが標準偏差
- 標準偏差は、元のデータと同じ単位でばらつきを表せる
- ビジネスでは、平均だけでなく、ばらつきや安定性を見ることが重要
