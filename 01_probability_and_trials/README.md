# 01 Probability and Trials

## 日本語

この章では、確率と試行について学びます。

確率は、1回の結果を正確に予言するものではありません。  
確率は、同じ条件で何度も試したときに、どのような傾向が現れやすいかを考えるための道具です。

この章では、10%で当たるくじを題材にして、1回の結果と繰り返したときの傾向の違いを観察します。

## この章の目的

この章では、次のことを理解することを目指します。

- 確率とは何か
- 試行とは何か
- 1回の試行と、繰り返しの試行の違い
- 確率と実際の結果は必ずしも一致しないこと
- 試行回数が増えると、結果の傾向が見えやすくなること
- Python を使って、確率的な現象をシミュレーションできること

## 確率とは何か

確率とは、ある出来事がどのくらい起こりやすいかを表す数値です。

例えば、当たりが出る確率が 10% のくじがあるとします。

このとき、10% という数値は「1回引いたら必ず0.1回当たる」という意味ではありません。  
1回の結果は、当たりかはずれのどちらかです。

10% という確率は、同じ条件で何度も試したときに、全体としてそのくらいの割合で当たりが出やすい、という意味です。

## 試行とは何か

試行とは、同じ条件で行う1回の実験や操作のことです。

例えば、次のようなものは試行として考えることができます。

- くじを1回引く
- サイコロを1回振る
- 商品ページを1人のユーザーが見る
- メールを1件送る
- 広告を1回表示する

ビジネス統計では、1回の試行だけで判断するのではなく、複数の試行を集めて傾向を見ることが重要です。

## 例：10%で当たるくじ

当たる確率が 10% のくじがあるとします。

このくじを1回引いた場合、結果は次のどちらかです。

- 当たり
- はずれ

この時点では、10%という確率を実感することは難しいです。

しかし、同じくじを100回、1000回、10000回と繰り返して引くと、当たりの割合が10%に近づく傾向が見えてきます。

ここで大切なのは、次の違いです。

- 1回の結果
- 繰り返したときの傾向

## Pythonでくじを表現する

Python では、乱数を使ってくじのような現象を表現できます。

```python
import random

if random.random() < 0.1:
    print("当たり")
else:
    print("はずれ")
```

`random.random()` は、0以上1未満の数をランダムに作ります。

その数が 0.1 より小さい場合を「当たり」と考えることで、10%で当たるくじを表現できます。

## 100回繰り返してみる

1回だけでは傾向は見えません。

そこで、10%で当たるくじを100回引いて、何回当たるかを数えます。

```python
import random

win_count = 0
trial_count = 100

for i in range(trial_count):
    if random.random() < 0.1:
        win_count += 1

print("試行回数:", trial_count)
print("当たり回数:", win_count)
print("当たりの割合:", win_count / trial_count)
```

実行するたびに、当たり回数は変わることがあります。

これは、確率と実際の結果が完全に一致するとは限らないからです。

## 試行回数を増やしてみる

次に、試行回数を変えて結果を比べます。

```python
import random

trial_counts = [10, 100, 1000, 10000]

for trial_count in trial_counts:
    win_count = 0

    for i in range(trial_count):
        if random.random() < 0.1:
            win_count += 1

    win_rate = win_count / trial_count

    print("試行回数:", trial_count, "当たり回数:", win_count, "当たりの割合:", win_rate)
```

試行回数が少ないと、当たりの割合は大きくぶれることがあります。

一方で、試行回数が増えると、当たりの割合は10%に近づきやすくなります。

## グラフで確認する

数字だけでなく、グラフで見ると傾向を確認しやすくなります。

```python
import random
import matplotlib.pyplot as plt

trial_counts = [10, 100, 1000, 10000]
win_rates = []

for trial_count in trial_counts:
    win_count = 0

    for i in range(trial_count):
        if random.random() < 0.1:
            win_count += 1

    win_rates.append(win_count / trial_count)

plt.bar([str(x) for x in trial_counts], win_rates)
plt.axhline(0.1, linestyle="--")
plt.xlabel("Number of Trials")
plt.ylabel("Win Rate")
plt.title("Win Rate by Number of Trials")
plt.show()
```

点線は、理論上の確率である 0.1 を表しています。

試行回数が増えると、実際の割合が理論上の確率に近づきやすくなることを観察できます。

## ビジネスとのつながり

ビジネスでは、1回の成功や失敗だけで判断すると危険なことがあります。

例えば、次のような場面です。

- 広告を1回出したら売れなかった
- メールを1件送ったら返信がなかった
- 商品ページを1人が見たが購入しなかった
- アンケートで1人が悪い評価をつけた

これらは重要な情報ではありますが、1回の結果だけで全体を判断することはできません。

ビジネス統計では、複数の試行やデータを集めて、全体としてどのような傾向があるのかを考えます。
