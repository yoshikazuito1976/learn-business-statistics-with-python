## Python の確認

Python では、計算やシミュレーションを行うことができます。

まずは、次のコードを実行してみます。

```python
print("Hello, Business Statistics")
```

次のように表示されれば、Python を実行できています。

```text
Hello, Business Statistics
```

## 簡単な計算

Python で簡単な計算をしてみます。

```python
price = 1000
tax_rate = 0.1

total = price + price * tax_rate

print(total)
```

この例では、1000円の商品に10%の税金を加えた金額を計算しています。

統計でも、まずは数値を扱うことから始まります。

## 乱数の確認

確率やシミュレーションでは、乱数を使います。

乱数とは、実行するたびに変わる可能性のある数のことです。

```python
import random

number = random.random()

print(number)
```

`random.random()` は、0以上1未満の数をランダムに作ります。

このコードを何度か実行してみてください。
実行するたびに、違う数が表示されることがあります。

## 10%で当たるくじ

乱数を使うと、くじのような現象を再現できます。

```python
import random

if random.random() < 0.1:
    print("当たり")
else:
    print("はずれ")
```

この例では、約10%の確率で「当たり」と表示されます。

ただし、1回実行しただけでは、10%という確率を実感することはできません。
確率の特徴は、何度も繰り返すことで見えてきます。

## 表計算ツールの確認

Excel や Google スプレッドシートでも、データの整理や集計を行うことができます。

例えば、次のような表を作ります。

| 試行回数 | 結果 |
| ---: | --- |
| 1 | はずれ |
| 2 | 当たり |
| 3 | はずれ |
| 4 | はずれ |
| 5 | はずれ |

表計算ツールでは、データを表として整理したり、件数を数えたり、グラフを作ったりできます。

Python と表計算ツールのどちらも、データを観察するための道具です。

## グラフ表示の確認

データの傾向は、表だけでなくグラフで見るとわかりやすくなります。

Python では、`matplotlib` を使ってグラフを表示できます。

```python
import matplotlib.pyplot as plt

values = [1, 2, 3, 4, 5]
counts = [2, 4, 6, 8, 10]

plt.bar(values, counts)
plt.show()
```

グラフが表示されれば、データを可視化する準備ができています。
